# Support

Before opening an issue:

1. Update to the latest release.
2. Run `headless-guard scan --explain`.
3. Check [Troubleshooting](docs/TROUBLESHOOTING.md).
4. Search open and closed issues.

Use GitHub Discussions for usage questions and ideas. Use the structured issue forms for bugs, false positives, and missed detections. Security issues must be reported privately through [GitHub Security Advisories](SECURITY.md#report-a-vulnerability).

Do not post raw command lines without redaction. They can contain URLs, tokens, proxy credentials, and user paths.
